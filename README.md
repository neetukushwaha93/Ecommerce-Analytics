# 🛒 Ecommerce Sales Analytics

A data analytics project built using **Python, MySQL, Pandas, Matplotlib, and Streamlit** to analyze ecommerce sales data and create an interactive dashboard.

## 📌 Project Overview

This project connects Python with a MySQL ecommerce database, analyzes completed orders, calculates sales performance, and displays the results through an interactive Streamlit dashboard.

## 🛠️ Technologies Used

- Python
- MySQL
- Pandas
- Matplotlib
- Streamlit
- mysql-connector-python
- python-dotenv

## 📂 Project Files

| File | Description |
|------|-------------|
| `app.py` | Streamlit interactive dashboard |
| `db.py` | MySQL database connection |
| `analysis.py` | Sales data analysis |
| `charts.py` | Sales charts and visualization |
| `requirements.txt` | Python dependencies |
| `.gitignore` | Protects sensitive files |

## 📊 Dashboard Features

- Total Sales
- Total Orders
- Total Products
- Average Sales
- Sales by Category
- Top 5 Products
- Monthly Sales
- Category Filter
- Sales Data Table
- Download Sales Data as CSV
